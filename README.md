# MitoRedox Atlas analysis code

This repository contains the analysis scripts accompanying *A multi-tissue atlas of mitochondrial cysteine redox modifications during ageing*. The scripts use study-specific input and reference tables.

| Script | Analysis |
| --- | --- |
| [01](analysis/01_prepare_mitochondrial_measurements.R) | Mitochondrial protein and PTM data preparation |
| [02](analysis/02_fit_tissue_and_age_contrasts.R) | Tissue and ageing contrasts |
| [03](analysis/03_test_pathway_enrichment.R) | Pathway enrichment and functional association networks |
| [04](analysis/04_reproduce_protein_ptm_coupling.R) | Protein–PTM and shared-site coupling analyses |
| [05](analysis/05_fit_sequence_and_structure_models.R) | Sequence and structure models and analysis of the external SSG dataset |
| [06](analysis/06_map_variants.py) | Protein sequence alignments and human variant mapping |
